## Mechanics that cost a session to learn

- **Merging.** Squash only; branches auto-delete on merge; main is not
  protected. `gh pr merge N --squash --delete-branch`, then pull main and
  delete the local branch.
- **Never stack a PR on another PR's branch.** When the base PR merges,
  GitHub auto-closes the stacked one and it cannot be retargeted. Recovery:
  `git rebase --onto main <duplicated-sha>`, push to a **new** branch, open
  a new PR. **Guardrail denies `git push --force`** (P1.git-push-force); do
  not retry it.
- **Guardrail's own hook mediates your shell.** A command whose interpreter
  literal (python -c, node -e, heredoc) mentions `guardrail` together with
  `night`, `setup`, `plane`, `operator` or `recover` is denied as
  P5.self-config. Put such scripts in a file and run the file; use the
  editor tool for source edits. The installed binary on this host is the
  release, so new rules bite only after the next update.
- **Windows CI runs a name-filtered slice** of the suite (`ci.yml`, the
  `-run 'Windows|BOM|…'` step). A test that only matters on Windows is
  invisible to CI unless its name starts with `TestWindows`. A test written
  on Linux can pass CI and fail on every Windows host (#332 was exactly
  that).
- **Path spelling on Windows.** `genconfig.HookCommand` writes hook
  commands quoted with forward slashes so they survive a POSIX shell (#149).
  Compare against `HookCommand(binary, …)`, never against a raw path.
- **Run the suite on real Linux before pushing.** WSL `Ubuntu-24.04` has Go
  at `/usr/local/go/bin` (not on the login PATH). Write a script file, then
  run it; an inline `-c` inherits the Windows PATH and breaks bash:

  ```bash
  #!/bin/bash
  export PATH=/usr/local/go/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
  export GOCACHE=/tmp/aghome/.cache/go-build GOMODCACHE=/tmp/aghome/go/pkg/mod
  mkdir -p "$GOCACHE" "$GOMODCACHE" /tmp/.git
  cd /mnt/c/Users/carlitos/projects/CtrlCarlitos/agent-guardrails || exit 1
  go vet ./... && go test ./... -count=1
  ```

  Invoke as `MSYS_NO_PATHCONV=1 wsl.exe -d Ubuntu-24.04 -- bash /mnt/c/<path>/script.sh`
  and strip NULs from the output (`tr -d '\0'`). Do **not** override `$HOME`
  (a home-dependent adapter test fails and looks like a real regression).
- **Installer harnesses.** `VERSION=v0.0.0-ci ./scripts/build-dist.sh`,
  then `DIST=dist VERSION=v0.0.0-ci pwsh -File test/installer/install_ps1_test.ps1`
  on Windows and `bash test/installer/install_sh_test.sh` on WSL. `dist/` is
  gitignored; remove it afterwards.
- **Measure before asserting.** Never state an engine verdict, an exit code
  or a "this passes" without running it in this session. Other agents plan
  against these claims.
- **Release recipe.** One PR that turns `## Unreleased` into
  `## vX.Y.Z-dev (date)` in `CHANGELOG.md` and bumps the version in the
  README install examples; squash it; `git tag -a vX.Y.Z-dev -m "…"` on the
  release commit; push the tag; `release.yml` publishes nine assets. Patch
  bumps are the norm even for ADR-level features.
- **Exit codes after ADR-0030.** `setup` / `plane enable` with no operator
  enrolled: 0 (armed by bootstrap), terminal or not. `setup --state
  disabled`, `plane disable`, `recover` with no operator enrolled: 3;
  without a terminal: 2. Enrolled and no terminal: 2 everywhere. Nothing to
  do: 0.
- `docs/windows-handover.md` predates the Windows broker lift; its
  "fail-closed on Windows" statements are historical (it says so at the
  top). Trust `CHANGELOG.md` and the ADRs over it.
- Writing `AGENTS.md` / `CLAUDE.md` at the repo root is denied to agents
  (self-config protection). The operator places those files; the draft the
